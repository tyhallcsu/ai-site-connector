# README artwork

Three original conceptual illustrations were generated with OpenAI image generation on 2026-10-05. They depict connections and access controls, not the plugin interface, a working site, certification, or a security guarantee. No customer data, credentials, third-party logos, or product screenshots were supplied.

| File | Purpose |

Outputs were proportionally resized as PNGs. The existing release builder excludes `assets/brand/*.png`, so this artwork does not increase the installed plugin ZIP. Existing SVG logos and the runtime admin mark remain unchanged. These illustrations follow the repository's existing MIT license; they are not official WordPress, Anthropic, or OpenAI branding.
